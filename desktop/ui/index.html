MyLock · 透明加密文件夹

M5 桌面端到端收口 — 本地优先 / 零知识 / 无账号 / 无遥测 / 无 AI。解锁后自动 net use 映射盘符，可像普通文件夹一样编辑；锁定时自动断开。此界面不是产品发布、安装包未签名、本版本未经第三方安全审计。
⚠ 使用前必读（第一次用请先看这里）
  1. 这不是「原地加密」：MyLock 不会把你已有的文件夹（例如 E:\testLock）变成加密文件夹，也没有「加密 / 解密」按钮。它是在另一个全新空路径新建一个「密文保险柜」目录；你原来的明文文件始终原样保留、MyLock 不会删。
  2. 「加密」= 把文件拖进解锁后的 Z: 盘；「解密」= 解锁后从 Z: 盘拷出来。锁定时磁盘上只剩密文，整个文件夹拷到移动硬盘仍是保险柜。
  3. 第一次用先点 ①「新建保险柜」；以后每次用点 ②「解锁并映射」。若直接拿一个还没有保险柜的路径去解锁，会提示「找不到 vault.meta」。
  4. 新建目标必须是全新空路径：若路径已存在且非空，建库会清空该目录（内核会 remove_dir_all）。请勿指向任何有文件的目录。
  5. 建库后会返回一串 Recovery Key——请立刻离线抄存，这是忘记口令时唯一的解锁兜底。
  6. 本版本未经第三方安全审计、安装包未代码签名；请勿存放不可替代的唯一副本。

① 第一次使用：新建保险柜（把原来的 Step 1 收进界面）

点击后会再次弹出确认框，把「不是原地加密 / 目标须全新空路径 / 会清空已存在目录 / 请抄存 Recovery Key」逐条念给你听。 仅在第一次建库时用；建好后不要再点（会拒绝覆盖非空目录）。
★ 请立刻离线抄存 Recovery Key（关闭本窗口后不会再次完整显示）
忘记主口令时用它解锁（填到上面「Recovery Key 展示码」框、主口令留空）。换口令 / 换 RK 是零吊销，真正吊销旧密钥要用 rotate-keys。

② 日常使用：解锁 → 编辑 → 锁定

就绪。第一次使用请先点「新建保险柜」；已有保险柜则填好路径与主口令后点「解锁并映射」，成功后在资源管理器里打开映射盘符（默认 Z:）。
安全边界（必须如实告知）： 这是 loopback-only WebDAV（引擎在桌面进程内，解锁后自动 net use Z: http://127.0.0.1:4918/）， 不是 WinFsp/FUSE 驱动级挂载；无 per-request 认证，任何本机进程都能访问挂载点； 仅在未解锁态防得住合法采集者，解锁态只缓解不消除；库外已存在的明文/临时副本锁定后不保证消失； 拒绝在 OneDrive / Dropbox / Google Drive / iCloud / 坚果云等同步目录内建库或挂载。

关于文件夹里的「隐藏 + 系统文件夹删除警告 + 保险柜图标」：这只是 shell 层提示， 用来减少误删（内部零件设为隐藏 + 系统、删除/移动时 Windows 会弹「You Are Deleting a System Folder」、 文件夹换成保险柜图标、并留一份可见的「⚠ 请勿删除.txt」）—— 不是防删 / 权限 / ACL 机制，不保证数据不丢失；请勿存放不可替代的唯一副本。
